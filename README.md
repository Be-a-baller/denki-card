# 点検カード

電気の安全点検で使う、お客さん説明カードと英会話練習のスマホ用Webアプリです。
HTML・CSS・JavaScript だけで動きます（ビルド不要）。オフラインでも使えて、ホーム画面に追加できます。

## できること
| モード | 中身 |
|---|---|
| 見せる | やさしい日本語／英語／中国語のカードを「次へ」で進める。返事ボタン・目次・よくある質問・分電盤の説明つき |
| 話す | 英語＋カタカナ読み（強く言うところは太字）＋意味＋別の言い方。「こう言われたら」「問題があったとき」「困ったときの一言」、フレーズ検索 |
| 練習 | 聞いてまねする／日本語→英語クイズ（「まだ」を多めに出す）／発音チェック（対応している端末だけ）。今日の1フレーズはホームに出る |
| 単語帳 | 英語・カタカナ・日本語・読み上げ。自分で追加・編集できる |
| 困ったときQ&A | 場面別のQ&A（やさしい・丁寧・英語）、検索、AIに聞く、自分のQ&Aを追加 |
| 設定 | 会社名、所要時間、問い合わせ番号、お知らせ写真、読み上げの速さ、CSVの書き出し・読み込み |

## 文を直すとき
- **phrases.json**：見せる・話す・練習・単語帳の文
- **qa.json**：困ったときQ&A
- 項目の意味は、それぞれのファイルの先頭の `_howto` に書いてあります
- 英語・カタカナ・中国語は下書きで、`review` に「要確認」の印が付いています。公式の言い方やネイティブの確認で直したら、`review` からその項目名を消してください
- 下書きの一覧は `review.html` で見られます（設定画面からも開けます）
- **直したら `sw.js` の `VERSION`（例：`'v1'` → `'v2'`）を1つ上げてください。** スマホ側が新しいファイルに入れ替わります

## 写真の差し替え
- お知らせの写真：アプリの「設定 → お知らせの写真 → 写真を選ぶ」（スマホの中だけに保存）
- 分電盤：`img/breaker.svg` を実物の写真（例：`img/breaker.jpg`）に替えて、phrases.json の `breakerImage` と、各部品の番号の位置 `x`・`y`（画像の左上からの%）を直す

## パソコンで確認する
```bash
cd このフォルダ
python3 -m http.server 8000
# → http://localhost:8000 を開く（ファイルを直接開くと文を読み込めません）
```

## スマホへの公開（無料）
### GitHub Pages（このアプリはこれで公開済み）
1. GitHub にこのフォルダの中身を入れたリポジトリを作る（公開リポジトリ）
2. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
3. 1〜2分で `https://ユーザー名.github.io/リポジトリ名/` で開けるようになる
4. 直したときは、ファイルを更新して push（`sw.js` の VERSION も上げる）

### Netlify Drop（いちばん簡単な別の方法）
1. https://app.netlify.com/drop を開く
2. このフォルダをまるごとドラッグ＆ドロップ
3. 出てきた URL をスマホで開く（アカウントを作ると URL を固定できる）

## スマホのホーム画面に追加する
- **iPhone（Safari）**：URL を開く → 下の共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：URL を開く → 右上の︙ → 「ホーム画面に追加」（または「アプリをインストール」）
- 追加したら、**電波のある場所で一度ひらいておく**と、そのあと電波がなくても使えます

## 注意
- お客さんの名前・住所などは一切保存しません。保存するのは、設定・練習の記録・自分で足した単語とQ&A・お知らせ写真だけ（スマホの中）
- 自分で足したデータはスマホを替えると消えるので、設定画面から CSV で書き出しておく
- 読み上げは端末の声を使います。中国語の声がない端末では、中国語の読み上げができません（設定画面で確認できます）
- 発音チェックと「AIに聞く」は電波が必要です。発音チェックの声は、文字にするために Google や Apple に送られます
- 最終判断は電気工事店・会社の指示に従ってください
